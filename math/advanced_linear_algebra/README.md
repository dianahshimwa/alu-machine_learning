# Advanced Linear Algebra

Functions for advanced matrix operations, implemented from scratch in Python.

## Files
- `0-determinant.py` — calculates the determinant of a matrix.
- `1-minor.py` — calculates the minor matrix of a matrix.
- `2-cofactor.py` — calculates the cofactor matrix of a matrix.
- `3-adjugate.py` — calculates the adjugate matrix of a matrix.
- `4-inverse.py` — calculates the inverse of a matrix, or None if singular.
- `5-definiteness.py` — classifies the definiteness of a matrix from its eigenvalues.
